# MCP Server Deployment Summary
Date: 2025-11-23
Status: ✅ OPERATIONAL (Direct Import Mode for Streamlit)

## 1. Deployment Overview

The FinOptiAgents application uses a dual-mode tool architecture:

### Streamlit UI (Production)
- **Mode:** Direct Python imports from `mcp_server/tools.py`
- **Reason:** Streamlit's event loop conflicts with MCP subprocess stdio communication
- **Implementation:** Tools imported directly in `app/agent.py` as `ALL_TOOLS` list
- **Status:** ✅ Working reliably

### Standalone/External Clients
- **Mode:** MCP Server subprocess via stdio
- **Implementation:** `mcp_server/main.py` running as FastMCP server
- **Use Cases:** `verify_mcp_connection.py`, external MCP clients, testing
- **Status:** ✅ Working (verified with test scripts)

## 2. Architecture Decision

### Why Direct Imports for Streamlit?

After extensive troubleshooting, the MCP subprocess approach proved incompatible with Streamlit due to:

1. **Event Loop Conflicts:** Streamlit's internal asyncio loop + nest_asyncio patches + anyio subprocess management created deadlocks
2. **Stdio Interference:** Timeout errors despite server processing requests (response lost in pipe)
3. **Complexity:** 135+ lines of monkeypatches couldn't resolve the fundamental incompatibility

### Solution: Hybrid Approach

- **Streamlit UI:** Import tools directly from `mcp_server/tools.py` (bypasses subprocess)
- **MCP Server:** Remains available for non-Streamlit use cases
- **Benefit:** Same tools, same code, different transport layer

```python

    send_email,

    # ... all 13 tools
```

## 6. Troubleshooting

### If Streamlit UI Fails
1. Check `app/agent.py` imports are correct
2. Verify `mcp_server/tools.py` has all tool definitions
3. Check `mcp_server/config.py` for environment setup

### If MCP Server Fails (Standalone)
1. Check `logs/mcp_server.log` for errors
2. Verify Python environment: `conda activate googleagentdevkit-new-nov-2025`
3. Run verification script to isolate issue

### Common Errors
- **ImportError:** Ensure `mcp_server/` is in PYTHONPATH
- **Secret Manager failures:** Check GCP credentials and project ID
- **Vertex AI errors:** Verify region and API enablement
